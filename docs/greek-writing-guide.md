## 1. Ορθογραφία

### 1.1 Καταλήξεις ρημάτων (η/ι/υ/ει/οι)
- Ρήματα, 3ο ενικό: πάντα **-ει** (και μετά από θα/να): γράφει, θα στείλει, να έρθει.
  ✗ θα έρθη, να δη → ✓ θα έρθει, να δει
- 2ο ενικό: **-εις**: θέλεις, μπορείς, θα δεις. ✗ θα δης → ✓ θα δεις
- Παθητική υποτακτική αορίστου: **-εί**: να σταλεί, να ενημερωθεί, να γίνει (όχι -ή).
- Αόριστος ρημάτων σε -ώ: **-ησ-**: επικοινωνήσω, ζητήσω, οργανώσω (-ωσ- για -ώνω). Εξαιρέσεις με -εσ-/-ασ-: καλέσω, φορέσω, γελάσω, περάσω.
  ✗ ζητίσαμε → ✓ ζητήσαμε
- Ρήματα σε -ίζω (καταχωρίζω, ορίζω, χαρίζω, αντικρίζω), σε -ύνω (διευκολύνω, μικρύνω), σε -αίνω (ανεβαίνω, ζεσταίνω, ομορφαίνω).

### 1.2 Ονόματα και επίθετα
- Άρθρο/κατάληξη: **η** = θηλυκό ενικό, **οι** = πληθυντικός αρσενικών και θηλυκών, **-ι** = πολλά ουδέτερα.
  ✗ η καλύτεροι bartenders → ✓ οι καλύτεροι bartenders · ✗ το ποτίρι → ✓ το ποτήρι
- Θηλυκά σε -η: η βάπτιση, η εκδήλωση, η εξυπηρέτηση, η πόλη. Γενική: της βάπτισης, πληθ. των βαπτίσεων.
- Επίθετα σε -ύς: ο ελαφρύς, η ελαφριά, το ελαφρύ. ✗ ελαφρή διάθεση (λόγιο) → ✓ ελαφριά διάθεση
- Επιρρήματα σε **-ως** (λόγια) γράφονται πάντα με ω: ακριβώς, αμέσως, ευτυχώς. ✗ ευτυχός → ✓ ευτυχώς
- Μετοχή ενεστώτα: **-ώντας** για ρήματα σε -ώ (μιλώντας, περνώντας), **-οντας** για ρήματα σε -ω (γράφοντας, κλείνοντας). ✗ περνόντας → ✓ περνώντας

### 1.3 -ται / -τε
- **-ται** = 3ο πρόσωπο παθητικής: γίνεται, παραδίδεται, σερβίρεται.
- **-τε** = 2ο πληθυντικό ενεργητικής: κλείνετε, θα λάβετε, επικοινωνήστε.
  ✗ Επικοινωνήσται μαζί μας → ✓ Επικοινωνήστε μαζί μας · ✗ Το μπαρ στήνετε σε 1 ώρα → ✓ Το μπαρ στήνεται σε 1 ώρα
- Παθητική προστακτική: **-είτε**: ενημερωθείτε, εγγραφείτε. ✗ εγγραφήτε

### 1.4 Τελικό -ν (σχολική γραμματική και ΕΕ)
- **Πάντα:** τον, στον, έναν, αυτόν, των, σαν. ✗ το Γιώργο → ✓ τον Γιώργο · ✗ ένα φίλο → ✓ έναν φίλο
- **Τη(ν), στη(ν), αυτή(ν), δε(ν), μη(ν):** κρατάμε το -ν πριν από φωνήεν ή κ, π, τ, ξ, ψ, γκ, μπ, ντ, τσ, τζ.
  ✓ την εκδήλωση, την Κυριακή, δεν μπορώ, μην τηλεφωνείτε · ✓ τη Δευτέρα, τη ζωή, δε θέλω, μη χάσετε
  Μνημονικό: «κάποτε έψαξα από ανάγκη το μπουγατσατζίδικο του Ντίνου».
- Πρακτικά: το «δεν» και το «μην» πριν από σύμφωνο γράφονται και με -ν σε πολλά σύγχρονα κείμενα. Διάλεξε έναν τρόπο και κράτα τον σε όλο το κείμενο· η ασυνέπεια φαίνεται.

### 1.5 της / τις / τους
- **της** = γενική ενικού θηλυκού ή «δικό της»: της νύφης, η τιμή της.
- **τις** = αιτιατική πληθυντικού θηλυκού: τις εκδηλώσεις, τις κρατήσεις, τις βλέπω.
- **τους** = αρσενικά πληθυντικού ή «δικό τους»: τους καλεσμένους, το πάρτι τους.
  ✗ για της εκδηλώσεις σας → ✓ για τις εκδηλώσεις σας · ✗ η πιο όμορφη μέρα της ζωή σας → ✓ της ζωής σας

### 1.6 -ής / -είς
- Επίθετα σε -ής: ενικός -ής, πληθυντικός αρσενικών/θηλυκών **-είς**: ακριβής → ακριβείς, συνεχής → συνεχείς, διεθνής → διεθνείς.
  ✗ συνεχής εκδηλώσεις → ✓ συνεχείς εκδηλώσεις · ✗ ακριβής ώρες → ✓ ακριβείς ώρες
- Ουσιαστικά σε -έας / -ής: ο συγγραφέας → οι συγγραφείς, ο συγγενής → οι συγγενείς.
- Ουδέτερο: ακριβές, συνεχές (✗ το συνεχή πρόγραμμα → ✓ το συνεχές πρόγραμμα).

### 1.7 -εία / -ία / -ια / -ιά
- **-εία** συνήθως από ρήματα σε -εύω/-εύομαι: πορεία, μαγεία, συνοδεία.
- **-ία** από ουσιαστικά και επίθετα: εμπειρία, φωτογραφία, τεχνολογία, ευκολία, παραγγελία, ειδωλολατρία.
- **-εια** (άτονο) από επίθετα σε -ής: ακρίβεια, αλήθεια, συνέπεια, υπερηφάνεια (αλλά περηφάνια).
- **-ιά** (τονισμένο) λαϊκά: ομορφιά, βραδιά, δουλειά, γειτονιά.
  ✗ εμπειρεία, παραγγελεία → ✓ εμπειρία, παραγγελία · Η ΕΕ προτιμά «εταιρεία» και «αντιπροσωπία».

### 1.8 Ό,τι / ότι και άλλες σημειώσεις
- **ό,τι** = οτιδήποτε: «Ό,τι χρειαστείτε, εδώ είμαστε.» · **ότι** = σύνδεσμος: «Πιστεύουμε ότι…»
- Μονολεκτικά (ΕΕ): απευθείας, καταρχάς, εξαιτίας, επιμέρους, εντούτοις, παρόλο που. Αλλά: εν λόγω, εν μέρει, παρ' όλα αυτά, γι' αυτό, απ' ό,τι.
- Καθένας, καθεμιά, καθετί: μία λέξη.

## 2. Τονισμός (μονοτονικό)

### 2.1 Βασικοί κανόνες
- Κάθε λέξη με 2+ συλλαβές παίρνει τόνο. Οι μονοσύλλαβες δεν παίρνουν: το, να, θα, με, σε, μου, πια, για, μια, ποιος, γεια.
  ✗ μιά, γιά, πιά, ποιός → ✓ μια, για, πια, ποιος
- **μια / μία, δυο / δύο:** «μια» = αόριστο άρθρο, «μία» = αριθμός (ΕΕ). «Μια ιδέα» · «μία ημέρα, όχι δύο».
- Μονοσύλλαβη προστακτική δεν τονίζεται ούτε με εγκλιτικά: ✓ πες μου, δες το, βρες μου το (✗ πές μου).

### 2.2 Μονοσύλλαβα που τονίζονται
- **ή** (διαζευκτικό): «γάμος ή βάπτιση». Το άρθρο **η** δεν τονίζεται.
- **πού / πώς** ερωτηματικά (ευθεία ή πλάγια ερώτηση): «Πού γίνεται;» «Πείτε μας πώς το φαντάζεστε.»
- **που / πως** χωρίς τόνο όταν δεν ρωτάνε: «Το μπαρ που διαλέξατε.» «Μας είπε πως είναι έτοιμος.»
  ✗ Δείτε που θα στηθεί το μπαρ → ✓ Δείτε πού θα στηθεί το μπαρ
- Αδύνατοι τύποι, όταν υπάρχει κίνδυνος παρανόησης: «Ο πατέρας μού είπε» (σε μένα) ≠ «Ο πατέρας μου είπε» (ο δικός μου).

### 2.3 Εγκλιτικά (δεύτερος τόνος)
- Λέξη τονισμένη στην **προπαραλήγουσα** + μου/σου/του/μας/σας/τους → δεύτερος τόνος στη λήγουσα:
  ✗ το τηλέφωνο σας → ✓ το τηλέφωνό σας · ✗ ο δάσκαλος μου → ✓ ο δάσκαλός μου · ✓ η κράτησή σας, το μήνυμά σας, το πρόγραμμά μας
- Παροξύτονη ή οξύτονη λέξη: **κανένας** δεύτερος τόνος: ✓ το σπίτι μου, η μητέρα της, η γιαγιά σου, η προσφορά σας.
- Δύο εγκλιτικά μετά από παροξύτονη: τονίζεται το πρώτο: ✓ δώσε μού το, φέρε μάς τα.

### 2.4 Κεφαλαία
- Αρχικό κεφαλαίο: ο τόνος μπαίνει αριστερά, πάνω: Άλλο, Έλα, Ώρα, Ήδη. ✗ Αλλο, Ετοιμο → ✓ Άλλο, Έτοιμο
- **Όλη η λέξη κεφαλαία: χωρίς τόνους.** ✗ ΚΡΆΤΗΣΗ → ✓ ΚΡΑΤΗΣΗ. Εξαίρεση: το διαζευκτικό **Ή** (ΓΑΜΟΣ Ή ΒΑΠΤΙΣΗ).
- Στα κεφαλαία **μένουν τα διαλυτικά** και προστίθενται όπου ο τόνος έδειχνε χωρισμό: νεράιδα → ΝΕΡΑΪΔΑ, Μάιος → ΜΑΪΟΣ, τρόλεϊ → ΤΡΟΛΕΪ, κοροϊδεύω → ΚΟΡΟΪΔΕΥΩ.
- Στο web, κουμπιά και τίτλοι σε ALL CAPS: γράψε πεζά με τόνους και άφησε το CSS (text-transform) να τα κάνει κεφαλαία. Έλεγξε ότι το site δεν δείχνει τόνους στα κεφαλαία.

### 2.5 Διαλυτικά
- Μπαίνουν στο ι/υ όταν δεν κάνει δίφθογγο με το προηγούμενο φωνήεν: προϋπόθεση, προϊόν, Ευρωπαϊκός, λαϊκός, πρωτεΐνη.
- Δεν μπαίνουν όταν τονίζεται το πρώτο φωνήεν (ο τόνος ήδη δείχνει χωρισμό): ρολόι, κέικ, τρόλεϊ, κοκτέιλ, τσάι.
- Τόνος και διαλυτικά μαζί όταν τονίζεται το ι/υ: Μαΐου, πρωτεΐνη, ταΐζω.
  ✗ Ευρωπαικός, προιόντα, τσάϊ → ✓ Ευρωπαϊκός, προϊόντα, τσάι

### 2.6 Έκθλιψη και αφαίρεση
- Μετά από έκθλιψη/αποκοπή η λέξη κρατά τον τόνο: «φέρ' το», «είν' ανάγκη».
- Η απόστροφος είναι ’ (U+2019), όχι ' ούτε ΄ (τόνος): ✓ γι’ αυτό, σ’ εσάς, θα ’ρθω.
- Για εμάς/εσάς: ✓ «σ’ εσάς», «μ’ εμένα» (πιο προσεγμένο από «σε σας», «με μένα»).

## 3. Γραμματική

### 3.1 Συμφωνία
- Επίθετο και μετοχή συμφωνούν με το ουσιαστικό σε γένος, αριθμό, πτώση:
  ✗ Το mobile bar είναι διαθέσιμος → ✓ Το mobile bar είναι διαθέσιμο · ✗ οι προσφορές μας ισχύουν για περιορισμένο χρόνο και είναι διαθέσιμοι → ✓ διαθέσιμες
- Ξένες λέξεις παίρνουν γένος, συνήθως ουδέτερο, και μένουν άκλιτες: το catering, το mobile bar, το van, το event, το DJ set· ο DJ, ο bartender. ✗ τα caterings, των events → ✓ τα catering, των event (ή: των εκδηλώσεων)
- Brand: διάλεξε γένος και κράτα το (π.χ. «το Vwanaki», «η Touristas Technologies»).
- Ευγενικός πληθυντικός προς ένα άτομο: ρήμα στον πληθυντικό, επίθετο στον ενικό: ✓ «Είστε σίγουρος;» «Είστε έτοιμη;» (✗ «Είστε σίγουροι;» όταν μιλάς σε έναν).

### 3.2 Άρθρο
- Τα ελληνικά βάζουν άρθρο εκεί που τα αγγλικά δεν βάζουν: σε κύρια ονόματα, αφηρημένες έννοιες, γενικεύσεις.
  ✗ Ποιότητα είναι προτεραιότητα μας → ✓ Η ποιότητα είναι η προτεραιότητά μας · ✓ ο Γιώργος, η Αθήνα, το Google
- Δεν βάζουν αόριστο άρθρο όπου τα αγγλικά βάζουν «a»: ✗ Είμαστε μια ομάδα από επαγγελματίες → ✓ Είμαστε ομάδα επαγγελματιών / Είμαστε επαγγελματίες
- Σε τίτλους και κουμπιά το άρθρο φεύγει: «Πακέτα Van Bar», «Ζητήστε προσφορά».

### 3.3 Ποιόν ενεργείας (στιγμιαίο / συνεχές)
- Το ρήμα έχει δύο θέματα: συνεχές (στέλνω) και στιγμιαίο (στείλω). Διάλεξε με βάση το νόημα, όχι το αγγλικό.
  - Μία φορά: θα στείλω, να καλέσετε, Κλείστε, Επικοινωνήστε.
  - Επανάληψη ή διάρκεια: θα στέλνω, να καλείτε, Κλείνετε (γενικά).
- ✗ Θα σας στέλνουμε την προσφορά αύριο → ✓ Θα σας στείλουμε την προσφορά αύριο
- ✗ Κάθε μήνα θα σας στείλουμε νέα (εννοείς συνέχεια) → ✓ Κάθε μήνα θα σας στέλνουμε νέα
- CTA: σχεδόν πάντα στιγμιαία προστακτική: Κλείστε, Ζητήστε, Δείτε, Καλέστε, Στείλτε.

### 3.4 «θα» + υποτακτική (μελλοντικός)
- Μελλοντικός = θα + τύπος υποτακτικής: θα στείλουμε, θα έρθει, θα γίνει. Οι καταλήξεις γράφονται όπως στην οριστική (-ει, -εις, -ουμε, -ετε, -ουν).
  ✗ θα σας ενημερώσουμαι → ✓ θα σας ενημερώσουμε · ✗ θα έρθη → ✓ θα έρθει
- Θέματα που μπερδεύουν: ✗ θα παραδόσουμε, να αποδόσει → ✓ θα παραδώσουμε, να αποδώσει (αλλά: παράδοση, απόδοση)
- Παθητικός: θα + -θώ: θα σταλεί, θα ενημερωθείτε, θα ολοκληρωθεί. ✗ θα σταλή → ✓ θα σταλεί
- Ευγενικό αίτημα: «θα ήθελα να…», «θα μπορούσατε να…;» Όχι «θα θέλω να» για ευγένεια.
- Μην αφήνεις το «θα» για βεβαιότητα που δεν έχεις: ✗ Θα ανεβείτε πρώτοι στο Google → ✓ Στόχος είναι να ανεβείτε στις πρώτες θέσεις.

### 3.5 Μετοχές
- Ενεργητική μετοχή (-οντας/-ώντας) είναι άκλιτη και έχει το **ίδιο υποκείμενο** με το ρήμα.
  ✗ Μπαίνοντας στο site, η προσφορά εμφανίζεται αμέσως → ✓ Μόλις μπείτε στο site, βλέπετε την προσφορά

## 4. Στίξη

- **Ερωτηματικό = ;** (όχι ?): «Πόσοι θα είστε;» Χωρίς κενό πριν.
- **Άνω τελεία = ·** (μισή παύση, ανάμεσα σε κόμμα και τελεία): «Το μπαρ στήνεται σε μία ώρα· εσείς απλώς απολαμβάνετε.» Χρήσιμη, αλλά με μέτρο.
- **Εισαγωγικά «»** για παράθεση και τίτλους, “ ” για εισαγωγικά μέσα σε εισαγωγικά. Χωρίς κενό μέσα: ✗ « Γάμοι » → ✓ «Γάμοι». ✗ "Γάμοι" σε ελληνικό κείμενο → ✓ «Γάμοι»
- **Κενά:** κανένα κενό πριν από , . ; · ! :. Ένα κενό μετά. Κενό ανάμεσα σε αριθμό και € (1.200 €).
- **Παύλες:** – (en dash) για διαστήματα: 20:00–02:00, Μάιος–Οκτώβριος. — (em dash) για παρένθεση, σε ζεύγος **χωρίς κενά μέσα** (Το van —με δύο bartenders— στήνεται σε μία ώρα). Διορθώθηκε από την v1· δες §18.2. Το ενωτικό - μόνο σε σύνθετα (Αϊ-Γιώργης, ελληνο-αγγλικός).
- **Θαυμαστικό:** ένα, σπάνια. ✗ Κλείστε τώρα!!! → ✓ Κλείστε ημερομηνία.
- **Αποσιωπητικά:** ένας χαρακτήρας … και σπάνια σε επαγγελματικό κείμενο.

### 4.1 Κόμμα
- **Χωρίς κόμμα** πριν από ειδικές προτάσεις (ότι, πως, που = ότι): ✗ Πιστεύουμε, ότι αξίζει → ✓ Πιστεύουμε ότι αξίζει
- **Χωρίς κόμμα** πριν από «να», πλάγια ερώτηση («αν» = whether) και διστακτικές (μήπως, μη): ✓ Ρωτήστε αν είναι διαθέσιμη η ημερομηνία. ✓ Φοβάστε μήπως δεν προλάβετε;
- **Χωρίς κόμμα** πριν από και, ούτε, ή, είτε (εκτός αν κλείνει παρένθεση).
- **Με κόμμα** όταν η υποθετική ή χρονική πρόταση προηγείται: ✓ Αν θέλετε κοκτέιλ με θέμα, πείτε μας. ✓ Όταν κλείσετε ημερομηνία, σας στέλνουμε το πρόγραμμα. Όταν ακολουθεί, το κόμμα συνήθως φεύγει: ✓ Πείτε μας αν θέλετε κοκτέιλ με θέμα.
- **Αναφορική με «που»:** χωρίς κόμμα όταν ξεχωρίζει (το πακέτο που διαλέξατε)· με κόμματα όταν απλώς προσθέτει: ✓ Το van, που χωράει δύο bartenders, στήνεται σε μία ώρα.
- **Με κόμμα** την προσφώνηση: ✓ Καλημέρα, Γιώργο. ✓ Γιώργο, έγινε.
- **Ποτέ** κόμμα ανάμεσα σε υποκείμενο και ρήμα: ✗ Το mobile bar μας, έρχεται παντού → ✓ Το mobile bar μας έρχεται παντού

## 5. Φυσική ελληνική διατύπωση αντί για αγγλισμούς (το πιο σημαντικό)

Τα αγγλικά αγαπούν ουσιαστικά, παθητική φωνή, κτητικά (your/our) και σταθερή σειρά λέξεων. Τα ελληνικά προτιμούν **ρήματα**, **ενεργητική φωνή**, **λιγότερα «σας/μας»** και **ευέλικτη σειρά** που βάζει μπροστά ό,τι θέλεις να τονίσεις.

### 5.1 Πέντε κανόνες
1. **Ρήμα, όχι ουσιαστικό.** «Πραγματοποιούμε την παράδοση» → «Παραδίδουμε».
2. **Ενεργητική φωνή.** «Το μπαρ στήνεται από την ομάδα μας» → «Στήνουμε το μπαρ».
3. **Κόψε τα κτητικά** όταν είναι αυτονόητα. «Κλείστε την ημερομηνία σας για την εκδήλωσή σας» → «Κλείστε ημερομηνία για την εκδήλωση».
4. **Σειρά λέξεων με έμφαση.** Το νέο ή σημαντικό πάει στην αρχή ή στο τέλος. «Για τον γάμο σας, εμείς φέρνουμε το μπαρ» είναι φυσικό· «Εμείς φέρνουμε το μπαρ για τον γάμο σας» επίσης. Μην αντιγράφεις τη σειρά του αγγλικού.
5. **Λιγότερη «δομή», περισσότερη ροή.** Σύνδεσε με «και», «αλλά», «γιατί», «έτσι», όχι με «Επιπλέον,», «Επιπροσθέτως,», «Ως εκ τούτου,» σε κάθε πρόταση.

- ✗ Θα ήθελα να σας ενημερώσω ότι η εργασία έχει ολοκληρωθεί επιτυχώς. → ✓ Τελείωσα. Όλα πήγαν καλά.
- ✗ Παρακαλώ βρείτε συνημμένο το αρχείο. (Please find attached) → ✓ Σας στέλνω συνημμένο το αρχείο. / Επισυνάπτω το αρχείο.
- ✗ Ελπίζω αυτό το email να σας βρίσκει καλά. → ✓ Καλημέρα σας, (και κατευθείαν στο θέμα)
- ✗ Παρακαλώ ενημερώστε με αν έχετε οποιεσδήποτε ερωτήσεις. → ✓ Αν έχετε απορίες, πείτε μου.
- ✗ Ανυπομονώ να ακούσω νέα σας. (Looking forward to hearing from you) → ✓ Περιμένω τα νέα σας.

### 5.4 Πότε κρατάμε αγγλικές λέξεις (SEO)
- **Κράτα** τον αγγλικό όρο όταν τον ψάχνουν έτσι οι Έλληνες και τον χρησιμοποιεί η αγορά: mobile bar, van bar, catering, DJ, cocktail bar, bartender, SEO, Google. Επιβεβαίωσε με δεδομένα αναζήτησης (GSC, Ahrefs), όχι από διαίσθηση.
- **Γράψ' τον με λατινικούς χαρακτήρες**, άκλιτο, με ελληνικό άρθρο: «το mobile bar», «στο catering», «οι bartenders» (ή «οι μπάρμεν» σε πιο λαϊκό ύφος). ✗ «το μομπάιλ μπαρ», «τα catering-ς»
- Κοκτέιλ: γράψε **κοκτέιλ** στο κείμενο (καθιερωμένο, ΛΚΝ) και «cocktail» μόνο όπου το απαιτεί το keyword.
- **Μη μεταφράζεις** καθιερωμένους όρους αγοράς σε τεχνητά ελληνικά («κινητό μπαρ» αντί για «mobile bar») αν δεν τα ψάχνει κανείς· αλλά στην πρόταση γύρω τους χρησιμοποίησε ελληνικά: «mobile bar για γάμο», όχι «mobile bar for weddings».
- **Ελληνικά** όπου η αναζήτηση είναι ελληνική: γάμος, βάπτιση, εκδήλωση, πάρτι, ενοικίαση.
- Μην κολλάς αγγλικά επίθετα: ✗ premium, exclusive, unique, amazing εμπειρία → ✓ προσεγμένο, μοναδικό (με απόδειξη).
- Στα chat με τον πελάτη, τεχνικοί όροι (title, meta description, H1, schema, redirect) μένουν αγγλικά, με μια φορά εξήγηση: «η περιγραφή που δείχνει το Google (meta description)».

### 5.5 Δάνεια που έχουν καθιερωθεί και δάνεια που ακούγονται μεταφρασμένα
- Κάθε μεταφραστικό δάνειο (calque) δεν είναι λάθος. Η Πύλη ορίζει το **μεταφραστικό δάνειο** ως λέξη ή φράση φτιαγμένη με ελληνικό υλικό κατά το πρότυπο ξένης. Πολλά έχουν καθιερωθεί εδώ και δεκαετίες:
  - **συνέδριο**: σημασιολογικό δάνειο από το γαλλικό congrès (el.wiktionary)
  - **υλοποιώ**: απόδοση του γαλλικού matérialiser (ΛΚΝ)
  - **λαμβάνει χώρα**: καταγράφεται στο ΛΚΝ ως έκφραση (= συμβαίνει)
- **Τεστ:** (1) Υπάρχει στο ΛΚΝ ή σε άλλο λεξικό; Αν όχι, είναι πρόσφατος αγγλισμός και θέλει αντικατάσταση (5.2). (2) Αν υπάρχει, ταιριάζει στο ύφος; Στο marketing η απλή λέξη κερδίζει (16.1).
- Περισσότεροι αγγλισμοί: ψευδόφιλοι στην §15, συμφράσεις στην §13, λόγιο λεξιλόγιο που φέρνει η μετάφραση στην §16.1, δομές πρότασης στην §9.7.

## 6. Ύφος και προσφώνηση

### 6.1 Εσείς ή εσύ;
| Περίπτωση | Επιλογή |
|---|---|
| Σελίδες επιχείρησης (γάμοι, βαπτίσεις, εταιρικά) | **εσείς** (σεβασμός, καλύπτει και ζευγάρια/οικογένειες) |
| Νεανικό brand, social, πάρτι | **εσύ**, αν το κάνει ήδη το brand |
| Πρώτο email σε επαγγελματία/B2B | **εσείς**, «Καλημέρα σας, κύριε Παπαδόπουλε,» |
| Chat με τον ιδιοκτήτη που σου μιλάει στον ενικό | **εσύ** (ακολούθα τον) |
- Σε μία σελίδα, ένα μόνο: ✗ «Κλείστε ημερομηνία… Στείλε μας μήνυμα» → ✓ «Κλείστε ημερομηνία… Στείλτε μας μήνυμα»
- Το «σας/Εσείς» δεν γράφεται με κεφαλαίο στο marketing (μόνο σε πολύ επίσημες επιστολές).
- Κλητική: Γιώργο, κύριε Παπαδόπουλε, κυρία Παπαδοπούλου. ✗ Αγαπητέ Γιώργος → ✓ Γιώργο,

### 6.2 Τόνος για ελληνικές μικρομεσαίες επιχειρήσεις
- Ζεστός, άμεσος, συγκεκριμένος. Λίγοι υπερθετικοί, πολλά στοιχεία (χρόνια, εκδηλώσεις, περιοχές, κριτικές).
- Οι Έλληνες εμπιστεύονται τον «άνθρωπο πίσω από την επιχείρηση»: πρώτο πρόσωπο πληθυντικού (εμείς) αρκεί, χωρίς εταιρική γλώσσα.
- Αποφεύγουμε την καθαρεύουσα στο marketing: ✗ εντός, εκτός αυτού, άνευ, ενίοτε, εν συνεχεία → ✓ μέσα σε, επίσης, χωρίς, καμιά φορά, μετά. (Στα επίσημα έγγραφα επιτρέπονται.)

### 6.3 Κεφαλαία αρχικά (Τριανταφυλλίδης, ΕΕ)
- **Κεφαλαίο:** ημέρες και μήνες (Δευτέρα, Οκτώβριος), εορτές (Πάσχα, Χριστούγεννα), εθνικά ως ουσιαστικά (Έλληνας, Αθηναίος), τοπωνύμια (Νότια Προάστια ως όρος, Κηφισιά), ονόματα εταιρειών/brands.
  ✗ τη δευτέρα 23 οκτωβρίου → ✓ τη Δευτέρα 23 Οκτωβρίου
- **Πεζό:** εποχές (καλοκαίρι), γλώσσες (τα αγγλικά), επίθετα από εθνικά (ελληνικό φαγητό), τίτλοι και αξιώματα (ο διευθυντής, ο δήμαρχος), γενικές έννοιες (το διαδίκτυο).
  ✗ μιλάμε Αγγλικά → ✓ μιλάμε αγγλικά (η Microsoft γράφει «στα Αγγλικά», αλλά ΕΕ και ΛΚΝ πεζό· κρατάμε πεζό, §19) · ✗ ο Διευθυντής Πωλήσεων μας → ✓ ο διευθυντής πωλήσεων
- **Τίτλοι σελίδων/H1:** κεφαλαίο μόνο στην πρώτη λέξη και στα κύρια ονόματα (sentence case), όχι σε κάθε λέξη. ✗ Mobile Bar Για Γάμους Στην Αθήνα → ✓ Mobile bar για γάμους στην Αθήνα (εξαίρεση: όροι brand/keyword που ο πελάτης γράφει με κεφαλαία, π.χ. «Mobile Bar»· κράτα συνέπεια).

## 7. SEO και copy

### 7.1 Αναζητήσεις χωρίς τόνους
- Οι χρήστες γράφουν συχνά χωρίς τόνους ή σε greeklish («mobile bar gamos», «βανακι μπαρ»). Το Google συνήθως ταιριάζει τονισμένες και άτονες μορφές, άρα **στο κείμενο γράφουμε πάντα σωστά, με τόνους**. Ποτέ άτονα keywords μέσα στο copy.
- Greeklish μόνο στα URL (slug): /mobile-bar-gamos/, /vaptiseis/. Μεταγραφή σταθερή (ΕΛΟΤ 743 ή όπως ήδη έχει το site), χωρίς τόνους και κεφαλαία.
- Τα ελληνικά κλίνονται: γάμος, γάμου, γάμο, γάμοι. Χρησιμοποίησε φυσικές πτώσεις, μην επαναλαμβάνεις την ονομαστική για να «χωρέσει» το keyword. ✗ «Mobile bar γάμος Αθήνα για γάμος» → ✓ «Mobile bar για γάμο στην Αθήνα»
- Title ~50–60 χαρακτήρες, meta description ~140–155. Τα ελληνικά είναι μακρύτερα από τα αγγλικά: γράψε πρώτα το keyword.
- Ερωτήσεις FAQ όπως τις ρωτάει ο κόσμος: «Πόσο κοστίζει ένα mobile bar για γάμο;» «Πόσες ώρες κρατάει;» Απάντηση στην πρώτη πρόταση (AEO/GEO), μετά λεπτομέρειες.

### 7.2 Αριθμοί, ποσά, ημερομηνίες
- **Χιλιάδες με τελεία, δεκαδικά με κόμμα:** 1.250,50 € · 12.000 επισκέψεις. (Η ΕΕ στις εκδόσεις της βάζει κενό: 125 000· στο ελληνικό web η τελεία είναι η συνήθης πρακτική.) Τα έτη ποτέ με τελεία: ✗ 2.026 → ✓ 2026
- **Νόμισμα:** ποσό, κενό, €: 450 € (ή «450 ευρώ» στο κείμενο). ✗ €450, 450€, 450.00 € → ✓ 450 €, 450,00 €
- **Ποσοστό:** 20% (στα ελληνικά συνήθως χωρίς κενό· η ΕΕ στις εκδόσεις βάζει κενό). Κράτα συνέπεια.
- **Ολογράφως ή ψηφία:** ψηφία για μετρήσεις, ποσά, στατιστικά· ολογράφως 1–9 σε απλό κείμενο αν διαβάζεται καλύτερα («τρία πακέτα»). Μία λέξη ως το δεκαεννιά, δεκάδες, εκατοντάδες: δεκαπέντε, είκοσι πέντε, εκατόν είκοσι.
- **Ημερομηνία:** 23 Οκτωβρίου 2026 (μήνας σε γενική) · σύντομη 23/10/2026 ή 23.10.2026. «στις 23 Οκτωβρίου», αλλά «την 1η Νοεμβρίου». ✗ 23 Οκτώβριος → ✓ 23 Οκτωβρίου · ✗ Οκτώβριος 23 → ✓ 23 Οκτωβρίου
- **Τακτικά:** 1η, 2ος, 3ο, 20ός αιώνας.
- **Ώρα:** 24ωρο: 14:00, 20:30 (η ΕΕ δέχεται και 14.00). Διάστημα: 20:00–02:00, «από τις 20:00 έως τις 02:00». ✗ 8pm → ✓ 20:00 · ✗ 2:00μμ → ✓ 14:00
- **Τηλέφωνο:** 10ψήφιο· σταθερό 210 123 4567, κινητό 69x xxx xxxx (π.χ. 694 123 4567). Διεθνές: +30 694 123 4567. Σε schema/`tel:` χωρίς κενά: +306941234567. Ίδια μορφή παντού στο site.
- **Διευθύνσεις:** «Λεωφ. Κηφισίας 12, 151 25 Μαρούσι» (ΤΚ 5 ψηφία, συνήθως κενό μετά τα 3).
- **Συντομογραφίες:** π.χ. (χωρίς κενό ανάμεσα), κ.λπ. ή κτλ., δηλ., τηλ., ΤΚ, κ. (κύριος/κυρία).

- **Ενικός** αν σου μιλάει στον ενικό. Χωρίς «Αγαπητέ», χωρίς «Ελπίζω να είσαι καλά» σε κάθε μήνυμα.
- **Φυσικές φράσεις:** «Έγινε.» «Το κοιτάζω.» «Το έφτιαξα.» «Σου στέλνω σε λίγο.» «Θες να το ανεβάσω;» «Μια ερώτηση πριν προχωρήσω:» «Δίκιο έχεις, το διορθώνω.» «Όλα καλά.»

## 9. Σύνταξη: πώς στήνεται η ελληνική πρόταση

Οι κανόνες εδώ είναι κυρίως από το Διοργανικό εγχειρίδιο της ΕΕ (10.9 «Προβλήματα απόδοσης»), τον οδηγό ύφους της Microsoft για τα ελληνικά και τη Γραμματική Ε΄–ΣΤ΄ Δημοτικού (ebooks.edu.gr). Όπου οι πηγές διαφωνούν, το σημειώνω.

### 9.1 Σειρά όρων και υπερβατό
- Η ελληνική έχει ελεύθερη σειρά λέξεων, όχι όμως αυθαίρετη. Οι λέξεις που δένουν μεταξύ τους (ουσιαστικό και ο προσδιορισμός του) μένουν **μαζί**. Αν τις χωρίσεις, έχεις **υπερβατό**, που το ΛΚΝ ορίζει ως σχήμα όπου «μια λέξη απομακρύνεται από μια άλλη, με την οποία βρίσκεται σε στενή λεκτική ή συντακτική σχέση». Είναι θεμιτό στην ποίηση, αλλά στο πεζό κείμενο μπερδεύει.
- Η ΕΕ το επισημαίνει ως συχνό λάθος μετάφρασης:
  ✗ η ανακοίνωση στην Επιτροπή της κ. Βασιλείου → ✓ η ανακοίνωση της κ. Βασιλείου στην Επιτροπή
  ✗ η εφαρμογή στα κράτη μέλη της οδηγίας → ✓ η εφαρμογή της οδηγίας στα κράτη μέλη
  Στο marketing: ✗ η οργάνωση στην Αθήνα του γάμου σας → ✓ η οργάνωση του γάμου σας στην Αθήνα.
- **Η γενική κολλάει στο ουσιαστικό της.** Ένας προθετικός προσδιορισμός ή ένα επίρρημα δεν μπαίνει ανάμεσα σε ουσιαστικό και γενική.
- **Το κτητικό πάει στο τέλος της ονοματικής φράσης** (Microsoft): ✓ «των προσωπικών δεδομένων σας» (όχι «των προσωπικών σας δεδομένων» σε τεχνικό κείμενο). Στον προφορικό λόγο και το λαϊκό ύφος το «το καινούργιο σας σπίτι» είναι φυσικό. Στο copy προτίμησε το «το σπίτι σας» και κόψε όσα κτητικά περισσεύουν (5.1).
- **Όχι πάνω από δύο γενικές στη σειρά** (Microsoft): ✗ η βελτίωση της ταχύτητας της φόρτωσης της σελίδας → ✓ να φορτώνει πιο γρήγορα η σελίδα.
- Το νέο ή σημαντικό πάει στο τέλος της πρότασης (θέση έμφασης) ή στην αρχή, με το «αυτό» ή το κλιτικό να το επαναλαμβάνει: «Τα κοκτέιλ τα φτιάχνουμε επί τόπου.» Αυτό το λέμε **διπλασιασμό του αντικειμένου** και είναι καθαρά ελληνικό.
- Τα αδύνατα κλιτικά (μου, σου, του, τον, το, μας, σας, τους) μπαίνουν **πριν** από το ρήμα στην οριστική και την υποτακτική («σας το στέλνουμε», «να σας το στείλουμε») και **μετά** στην προστακτική και τη μετοχή («στείλτε μας το», «στέλνοντάς σας»). Όταν είναι δύο, ο έμμεσος (σε ποιον) μπαίνει πριν από τον άμεσο (τι): σας το, μου τα. (Βασική γραμματική· αναλυτικά στον Holton κ.ά., ενότητες για τις αδύνατες αντωνυμίες.)

### 9.2 Μετοχές (συμπλήρωμα στο 3.5)
- **Το υποκείμενο της μετοχής = το υποκείμενο του ρήματος** (ΕΕ). Αλλιώς η μετοχή «κρέμεται»:
  ✗ Έχοντας εξετάσει την πρόταση, η απόφαση είναι θετική. → ✓ Αφού εξετάσαμε την πρόταση, αποφασίσαμε θετικά.
  ✗ Κλείνοντας ημερομηνία, η ομάδα μας θα σας καλέσει. → ✓ Μόλις κλείσετε ημερομηνία, θα σας καλέσουμε.
- Οι λόγιες μετοχές σε -ων/-ουσα/-ον κάνουν γενική σε **-οντος** ή **-ντος**: του παρόντος, του ενδιαφέροντος, του περιβάλλοντος. Όταν έχουν γίνει ουσιαστικά της κοινής κλίσης, κάνουν -α: ο ορίζοντας, του ορίζοντα· ο παράγοντας, του παράγοντα (ΕΕ).
- Η κλιτή μετοχή (-μένος) κλίνεται σαν επίθετο σε -ος, -η, -ο. Πολλές έγιναν ουσιαστικά: το περιεχόμενο, το ενδεχόμενο, τα χρωστούμενα (Γραμματική Ε΄–ΣΤ΄).
- Η μετοχή σε -οντας/-ώντας δεν κλίνεται και δεν παίρνει άρθρο. Για αγγλικό -ing σε τίτλο ή λίστα, χρησιμοποίησε ουσιαστικό ή ρήμα: ✗ «Οργανώνοντας τον γάμο» (τίτλος) → ✓ «Οργάνωση γάμου» ή «Πώς οργανώνουμε τον γάμο».

### 9.3 Δευτερεύουσες προτάσεις
- **Ειδικές** (ότι, πως, που): χωρίς κόμμα πριν (4.1). Το «ότι» είναι ουδέτερο, το «πως» πιο προφορικό. Μην τα ανακατεύεις στην ίδια παράγραφο.
- **Πλάγιες ερωτήσεις:** με **αν**, όχι «εάν» (ΕΕ). Το «εάν» είναι λόγιο· η Microsoft προτείνει γενικά «αν» και στις υποθετικές. ✓ «Ρωτήστε αν είναι ελεύθερη η ημερομηνία.»
- **Αναφορικές:** στο απλό κείμενο **που**, όχι «ο οποίος» σε κάθε πρόταση (5.2 #33). Η Microsoft προτείνει να αποφεύγεις τελείως την αναφορική όταν γίνεται:
  ✗ η ενημέρωση στην οποία προβαίνει ο διακομιστής → ✓ η ενημέρωση του διακομιστή.
  Το «ο οποίος» χρειάζεται μόνο όταν το «που» δημιουργεί ασάφεια ή μετά από πρόθεση: «η αίθουσα στην οποία θα γίνει η δεξίωση» (ή «η αίθουσα όπου θα γίνει»).
- **Τελικές:** «για να» στο απλό ύφος· «ώστε να», «προκειμένου να» είναι λόγια (5.2 #27).
- **Υποθετικές:** «αν» + οριστική ή υποτακτική· όταν προηγείται, παίρνει κόμμα (4.1).
- **Χρονικές:** «όταν/μόλις/αφού» + υποτακτική για το μέλλον: «Μόλις λάβουμε το μήνυμα, σας απαντάμε.» ✗ «Μόλις θα λάβουμε».

### 9.4 Συμφωνία και έλξη
- **Όχι έλξη στο «όσοι»** (ΕΕ, gnomikologikon). Το «όσοι» παίρνει την πτώση που θέλει η δική του πρόταση:
  ✗ Καλούμε όλους όσους ενδιαφέρονται → ✓ Καλούμε όλους όσοι ενδιαφέρονται.
  Εδώ το «όσοι» είναι υποκείμενο του «ενδιαφέρονται», άρα μένει στην ονομαστική, ακόμα κι αν το «όλους» είναι αιτιατική. Ίδια λογική: ✓ «Ευχαριστούμε όλους όσοι μας εμπιστεύτηκαν.»
  Κανόνας: ρώτα ποιο ρόλο έχει το «όσοι» **μέσα στη δική του πρόταση**. Αν είναι υποκείμενο, βάζεις ονομαστική. Αν είναι αντικείμενο, αιτιατική: ✓ «όλους όσους καλέσατε».
- ✓ «περισσότεροι από **έναν**» ή «περισσότεροι του ενός» (✗ περισσότεροι από ένας) (gnomikologikon): «Μας το ζήτησαν περισσότεροι από έναν πελάτες.»
- Περιληπτικά και ποσοτικά: «Η πλειονότητα των πελατών **προτιμά**…» (ρήμα στον ενικό, γιατί το υποκείμενο είναι η «πλειονότητα»).
- Θηλυκά σε -ος (η μέθοδος, η είσοδος, η περίοδος) παίρνουν θηλυκά επίθετα και αντωνυμίες: ✓ οι μέθοδοι αυτές, η κύρια είσοδος (gnomikologikon).
- Το «επικεφαλής» είναι άκλιτο: ✓ του επικεφαλής, των επικεφαλής (✗ του επικεφαλή).
- Το επίθετο «ενεργός» έχει θηλυκό πληθυντικό **ενεργές** (ΕΕ): ✓ οι ενεργές προσφορές.

### 9.5 Προθέσεις που μπερδεύουν
| Θέμα | ✓ Γράψε | Σημείωση / πηγή |
|---|---|---|
| πριν | **πριν από** την εκδήλωση | Όχι «πριν την» στο γραπτό (ΕΕ). |
| μετά | **μετά την** εκδήλωση · **ύστερα από / έπειτα από** συζήτηση | ΕΕ: «μετά από» μόνο πριν από ουσιαστικό χωρίς άρθρο, και προτιμά «ύστερα από/έπειτα από». Ο Μπαμπινιώτης δέχεται «μετά από» χωρίς άρθρο. Δες §19. |
| ως / σαν | **ως** = με την ιδιότητα · **σαν** = παρομοίωση | «Ως bartender έχω δουλέψει σε 200 γάμους.» «Λάμπει σαν διαμάντι.» Το «ως» συμφωνεί σε πτώση: «με την ιδιότητά του ως θεματοφύλακα» / «η Επιτροπή, ως θεματοφύλακας,» (ΕΕ). |
| ως / έως | **έως** για όρια και διαστήματα | «από 50 έως 200 άτομα», «έως τις 02:00» (Microsoft). Το «ως» στο απλό ύφος («ως το πρωί») είναι αποδεκτό. |
| όπως | ίδια πτώση με το προηγούμενο ή «όπως είναι» + ονομαστική | ✓ «σε εκδηλώσεις όπως γάμους και βαπτίσεις» ή «όπως είναι οι γάμοι» (Microsoft). |
| αφορά | **αφορά τον/την/το** + αιτιατική | Όλα τα λεξικά δίνουν πρώτα την αιτιατική. Το «αφορά σε» είναι λόγιο. Ο Μπαμπινιώτης το θεωρεί πιο προσεγμένο, η Microsoft το αποφεύγει. Δες §19. |
| όσον αφορά | **όσον αφορά το/τα** + αιτιατική | ✗ «όσον αφορά στο» (ΛΚΝ, gnomikologikon). |
| σύμφωνα με | **σύμφωνα με** τους όρους | Το «βάσει» θέλει γενική (βάσει του προγράμματος). Το «με βάση» θέλει αιτιατική (με βάση το πρόγραμμα). |
| ανεξαρτήτως | **ανεξαρτήτως** ηλικίας (+ γενική) / **ανεξάρτητα από** την ηλικία | ✗ ανεξαρτήτου (gnomikologikon) |
| στο πλαίσιο | **στο πλαίσιο** της εκδήλωσης (ενικός) | ✗ «στα πλαίσια» (gnomikologikon). Στον προφορικό λόγο το «στα πλαίσια» είναι πολύ διαδεδομένο· στο γραπτό κράτα τον ενικό. |

### 9.6 Λόγια ρήματα: αιτιατική, όχι γενική
- Στη νέα ελληνική τα λόγια ρήματα που στα αρχαία έπαιρναν γενική ή δοτική παίρνουν **αιτιατική** (ΕΕ): ✓ «επιδέχεται άμεση εφαρμογή» (✗ άμεσης εφαρμογής).
- Εξαίρεση: στερεότυπες λόγιες φράσεις κρατούν τη γενική, π.χ. «απολαμβάνει της εμπιστοσύνης» (ΛΚΝ: «λόγ., με γεν.»· gnomikologikon). Στο marketing γράψε απλά: «μας εμπιστεύονται».
- Το «διαρρέω» είναι αμετάβατο (gnomikologikon): ✓ «διέρρευσαν πληροφορίες» (✗ διέρρευσαν την πληροφορία). Για μεταβατική σημασία: «έδωσαν στη δημοσιότητα».

### 9.7 Ελληνική ροή αντί για αγγλική δομή (συμπλήρωμα στο 5.3)
- **Ρήμα στην αρχή** είναι φυσικό στα ελληνικά: «Έρχεται το καλοκαίρι και γεμίζουν οι ημερομηνίες.» Τα αγγλικά θέλουν πάντα υποκείμενο πρώτο, τα ελληνικά όχι.
- **Το υποκείμενο-αντωνυμία παραλείπεται:** ✗ «Εμείς φτιάχνουμε… Εμείς στήνουμε…» → ✓ «Φτιάχνουμε… Στήνουμε…». Το «εμείς» μπαίνει μόνο για αντίθεση: «Εσείς διασκεδάζετε, εμείς αναλαμβάνουμε τα υπόλοιπα.»
- **Αποφεύγεις τα σχήματα «Αυτό που…είναι»** (cleft): ✗ «Αυτό που μας κάνει να ξεχωρίζουμε είναι η εμπειρία» → ✓ «Ξεχωρίζουμε για την εμπειρία μας.»
- **Τίτλοι με ουσιαστικό ή ερώτηση**, όχι με μετοχή ή «Πώς να…» μεταφρασμένο από το «How to»: ✓ «Πώς διαλέγετε mobile bar για τον γάμο» ή «Mobile bar για γάμο: τι να προσέξετε».

## 10. Ρήματα: θέματα, αύξηση, τύποι που μπερδεύουν

### 10.1 Ρήματα σε -άγω και -βάλλω (συνεχές / στιγμιαίο)
Πηγή: Γραμματική Ε΄–ΣΤ΄ Δημοτικού, 10.2Δ· ΕΕ 10.9.
| Ρήμα | Συνεχές (επανάληψη, διάρκεια) | Στιγμιαίο (μία φορά) | Συντελεσμένο |
|---|---|---|---|
| εισάγω | εισάγω, να εισάγετε | να **εισαγάγετε**, θα εισαγάγουμε | έχω εισαγάγει |
| εξάγω | εξάγει (κάθε χρόνο) | θα **εξαγάγει** (μία φορά) | έχει εξαγάγει |
| διεξάγω | διεξάγουμε (κάθε χρόνο) | θα **διεξαγάγουμε** | έχει διεξαχθεί |
| παράγω | παράγουμε | να **παραγάγουμε** | έχουμε παραγάγει |
| προβάλλω | προβάλλουμε (συνέχεια) | να **προβάλουμε** (ένα λ) | έχουμε προβάλει |
| αναβάλλω | ανέβαλλε (συστηματικά) | **ανέβαλε** (χτες) | έχει αναβάλει |
| υποβάλλω | υποβάλλετε (κάθε φορά) | να **υποβάλετε** την αίτηση | έχετε υποβάλει |
| συμμετέχω | συμμετέχω | να **συμμετάσχω** | έχω συμμετάσχει |
- Κανόνας: στο συνεχές το θέμα είναι **αγ-** / **βάλλ-** (δύο λ). Στο στιγμιαίο είναι **αγαγ-** / **βαλ-** (ένα λ).
- Στις οδηγίες για μία ενέργεια (φόρμες, CTA) χρησιμοποιείς στιγμιαίο: ✓ «Εισαγάγετε το email σας» (Microsoft). Στον προφορικό λόγο ακούγεται και το «Εισάγετε»· στο γραπτό κείμενο κράτα το σωστό.
- Στο marketing συχνά υπάρχει απλούστερο ρήμα: «Γράψτε το email σας» αντί για «Εισαγάγετε».

### 10.2 Εσωτερική αύξηση (λόγια σύνθετα)
Πηγή: ΕΕ 10.9.
- **Κρατούν** αύξηση όσα σύνθετα είναι λόγια: κατέθεσε, επέβαλε, διέπραξε, απέκρουσε, ανέλαβε, υπέβαλε, παρέσχε.
- **Δεν κρατούν** όσα έχουν γίνει κοινά: επισήμανε, εξάντλησε, πρόσθεσε, κατάλαβε.
- Η αύξηση φεύγει όταν ο τόνος δεν πέφτει πάνω της: ανέλαβα αλλά αναλάβαμε, υπέβαλα αλλά υποβάλαμε.
- Στην **προστακτική** δεν μπαίνει αύξηση (gnomikologikon): ✓ επανάλαβε (✗ επανέλαβε), ✓ παράγγειλέ μου (✗ παρήγγειλέ μου), ✓ υπόγραψε (3.7).

### 10.3 Μεσοπαθητικά: τύποι που μπερδεύουν
Πηγή: gnomikologikon· ΛΚΝ (διαθέτω).
| ✓ Σωστό | ✗ Λάθος / μεικτό |
|---|---|
| αντικαθίστανται, αποκαθίστανται | αντικαθιστώνται, αποκαθιστώνται |
| διατίθενται (και προφ. διαθέτονται) | διατίθονται |
| αποκτώνται | αποκτούνται |
| οι τιμές αυξάνονται | οι τιμές αυξάνουν (στο γραπτό· πολύ διαδεδομένο στον προφορικό) |
| θεωρούνταν, δικαιούνταν | θεωρείτο, δικαιούτο: λόγια κατάληξη χωρίς την αύξηση. Η ΕΕ το λέει «υβριδικό τύπο» και δεν τον δέχεται. |
| χαρακτηρίστηκε, ορίστηκε, δοκιμάστηκε (στ) | χαρακτηρίσθηκε, ορίσθηκε (σθ, λόγιο, παλιό) |
- Τα ρήματα σε -ίζω, -άζω, -έζω γράφουν **-στηκε** στον παθητικό αόριστο, όχι «-σθηκε» (ΕΕ).

### 10.4 Ρήματα σε -ώ: δύο συζυγίες
- Το «πληρώ» κάνει **πληροί**, **πληρούν** (ΕΕ): ✓ «Η αίθουσα πληροί τις προδιαγραφές.» Στο marketing: «Η αίθουσα έχει ό,τι χρειάζεται.»
- Ρήματα που κλίνονται και στις δύο συζυγίες (αγαπάω/αγαπώ, μιλάω/μιλώ): στο copy διάλεξε το ένα. Το **-άω** είναι πιο προφορικό και ζεστό, το **-ώ** πιο ουδέτερο.

## 11. Πίνακες κλίσης για συχνά λάθη

### 11.1 Επίθετα σε -ής, -ές (ακριβής, συνεχής, διεθνής, δημοφιλής)
Πηγή: Γραμματική Ε΄–ΣΤ΄ Δημοτικού, 7.1Η.
| | Αρσ./Θηλ. ενικός | Ουδ. ενικός | Αρσ./Θηλ. πληθ. | Ουδ. πληθ. |
|---|---|---|---|---|
| Ονομ. | ο/η ακριβής | το ακριβές | οι ακριβείς | τα ακριβή |
| Γεν. | του/της ακριβούς | του ακριβούς | των ακριβών | των ακριβών |
| Αιτ. | τον/την ακριβή | το ακριβές | τους/τις ακριβείς | τα ακριβή |
- Στον καθημερινό λόγο ακούγεται και η γενική «του ακριβή». Στο γραπτό κείμενο: **του ακριβούς, της συνεχούς, του διεθνούς**.
- ✓ «προϊόντα ευρείας κατανάλωσης», «διεθνούς φήμης», «συνεχούς λειτουργίας».

### 11.2 Επίθετα σε -ύς, -εία, -ύ (ευρύς, ταχύς, ευθύς, οξύς)
Πηγή: ίδια ενότητα.
| | Αρσ. | Θηλ. | Ουδ. |
|---|---|---|---|
| Ονομ. ενικ. | ο ευρύς | η ευρεία | το ευρύ |
| Γεν. ενικ. | του ευρέος | της ευρείας | του ευρέος |
| Ονομ. πληθ. | οι ευρείς | οι ευρείες | τα ευρέα |
| Γεν. πληθ. | των ευρέων | των ευρειών | των ευρέων |
- Ζουν κυρίως σε στερεότυπες φράσεις: ευρεία γκάμα, ευθεία γραμμή, ταχεία (αμαξοστοιχία), ευρείας κατανάλωσης.
- Οι λαϊκοί τύποι σε -ύς, -ιά, -ύ (βαθύς, βαθιά, βαθύ· ελαφρύς, ελαφριά) είναι άλλη κλίση (1.2). Μην τις ανακατεύεις: ✗ ευριά, ✗ βαθεία.

### 11.3 Λόγιες μετοχές και επίθετα σε -ων, -ουσα, -ον
| Ονομ. | Γεν. ενικού | Σημείωση |
|---|---|---|
| το παρόν | του παρόντος | «το παρόν έγγραφο», «του παρόντος» (ΕΕ) |
| το ενδιαφέρον | του ενδιαφέροντος | ✗ του ενδιαφέρον |
| το περιβάλλον | του περιβάλλοντος | ✗ του περιβάλλον |
| ο ορίζοντας | του ορίζοντα | πέρασε στην κοινή κλίση (ΕΕ) |
| ο παράγοντας | του παράγοντα | ίδιο |

### 11.4 Σύνθετα με ενωτικό: κλίνονται και τα δύο μέρη
Πηγή: Microsoft· ΕΕ 10.1.8.
| | Ενικός | Πληθυντικός |
|---|---|---|
| Ονομ. | η λέξη-κλειδί | οι λέξεις-κλειδιά |
| Γεν. | της λέξης-κλειδιού | των λέξεων-κλειδιών |
| Αιτ. | τη λέξη-κλειδί | τις λέξεις-κλειδιά |
Ίδια λογική: η απόφαση-πλαίσιο → οι αποφάσεις-πλαίσια· ο σταθμός-βάση → οι σταθμοί-βάσεις. Στο SEO copy, αν ακούγεται βαρύ, γράψε «οι κύριες λέξεις αναζήτησης».

### 11.5 Ουδέτερα σε -ιο με δύο γενικές
Πηγή: el.wiktionary (συνέδριο).
- το συνέδριο → του συνεδρίου (λόγιο, συνηθέστερο στο γραπτό) / του συνέδριου. Πληθ.: των συνεδρίων / των συνέδριων. Παρόμοια: γραφείο, εργαστήριο, κτίριο, ταμείο.
- Στο γραπτό κείμενο διάλεξε **τον λόγιο τονισμό** (του συνεδρίου, του κτιρίου) και κράτα τον ίδιο σε όλο το κείμενο.

### 11.6 Ξένες λέξεις και αρκτικόλεξα: γένος
Πηγή: Microsoft· ΛΚΝ.
- Οι ξένες λέξεις μένουν **άκλιτες** και παίρνουν το γένος της ελληνικής λέξης που αντιστοιχεί (Microsoft): η SQL (γλώσσα), η ΔΕΗ (επιχείρηση), το email (μήνυμα). Αν δεν υπάρχει προφανές ελληνικό αντίστοιχο, παίρνουν **ουδέτερο**.
- Γένη όπως τα καταγράφει το ΛΚΝ: **το** κοκτέιλ, **το** μπαρ, **το** πάρτι (άκλιτα). Ο bartender / ο DJ ακολουθούν το φύλο του προσώπου: ο/η DJ, ο/η bartender.
- Άκλιτα και στον πληθυντικό: τα κοκτέιλ, τα πάρτι, τα μπαρ (✗ τα κοκτέιλς, ✗ τα πάρτια· το «μπαράκια» είναι υποκοριστικό του ΛΚΝ).

### 11.7 Αριθμητικά που κλίνονται ή γράφονται λάθος
Πηγή: gnomikologikon· Τριανταφυλλίδης.
| Θέμα | ✓ Σωστό | ✗ Λάθος |
|---|---|---|
| μισό + αρσ./θηλ. | τρεισήμισι μέρες, τεσσερισήμισι ώρες | τριάμισι μέρες |
| μισό + ουδέτερο | τριάμισι χρόνια, τεσσεράμισι κιλά | τρεισήμισι χρόνια |
| τρεις / τέσσερις | τρεις εκδηλώσεις, τέσσερις ώρες (θηλ./αρσ.) · τρία πακέτα, τέσσερα κοκτέιλ (ουδ.) | τρείς (με τόνο) · τέσσερεις |
| εννιά / ένατος | εννιά (ή εννέα) · ένατος (ένα ν) | έννατος |
| ημερομηνία | 15 Σεπτεμβρίου ή 15 του Σεπτέμβρη | 15 Σεπτέμβρη, 15 Σεπτέμβριος |
| χίλιοι | χίλιοι καλεσμένοι, χίλιες θέσεις, χίλια άτομα · δύο χιλιάδες | δύο χίλιες |

## 12. Συλλαβισμός (για αλλαγή γραμμής και τυπογραφία)
Πηγή: users.sch.gr/ipap, με βάση Χατζησαββίδη (ΟΕΔΒ 2011), Τριανταφυλλίδη (1941), Holton κ.ά. (1999), Κλαίρη–Μπαμπινιώτη (2005).

Στο web η αλλαγή γραμμής γίνεται συνήθως αυτόματα. Οι κανόνες χρειάζονται όταν κόβεις λέξη με το χέρι (PDF, έντυπο, εικόνα, banner) ή όταν ρυθμίζεις το `hyphens: auto` με `lang="el"`.
1. **Ένα σύμφωνο ανάμεσα σε φωνήεντα** πάει με το επόμενο φωνήεν: ώ-ρα, έ-λα, κα-λε-σμέ-νοι.
2. **Δύο ή περισσότερα σύμφωνα:** πάνε μαζί με το επόμενο φωνήεν αν **μπορεί να αρχίσει με αυτά ελληνική λέξη**: έ-κτι-ζε (κτίριο), βι-βλί-ο (βλάβη), ει-σφέ-ρω (σφαίρα), κά-στρο (στρώμα), ε-χθρι-κός (χθες). Αλλιώς χωρίζονται: σύμ-φω-να (καμία λέξη σε μφ-), αρ-χί-ζει (καμία σε ρχ-), αν-θρω-πιά (καμία σε νθ-), αμ-βρο-σί-α.
3. **Δύο ίδια σύμφωνα** χωρίζονται πάντα, και το γγ: Σάβ-βα-το, συλ-λα-βή, εν-νιά, αγ-γα-ρεί-α, θά-λασ-σα.
4. **Δίψηφα σύμφωνα** (μπ, ντ, γκ, τσ, τζ) δεν χωρίζονται: α-μπέ-λι, δα-ντέ-λα, έ-γκυ-ρος, βό-τσα-λο, γρα-τζου-νιά.
5. **Δίψηφα φωνήεντα** (αι, ει, οι, ου, υι) και τα αυ, ευ δεν χωρίζονται: πε-ρι-ου-σί-α, παι-δεί-α, α-νά-παυ-ση, πι-στεύ-ω.
6. **Σύνθετες λέξεις:** ακολουθούν τους ίδιους κανόνες, όχι τα συνθετικά τους: συ-νά-γω, προ-σέ-χω, ε-κλέ-γω. Το παλιό «συν-ά-γω», «εκ-λέ-γω» δεν ισχύει πια.
7. Μην αφήνεις ένα μόνο γράμμα στο τέλος ή στην αρχή γραμμής (α-|πό ✗). Μην κόβεις αριθμό από τη μονάδα του (450 | € ✗, ΕΕ).

| make a decision | κάνω απόφαση | **παίρνω** απόφαση |
| take part | — | **παίρνω μέρος** (απλό), **λαμβάνω μέρος** (λόγιο) |

| book a room / a seat | κάνω book, κάνω κράτηση (✓ λόγιο) | **κλείνω** δωμάτιο / θέση / τραπέζι |
| close a deal | κλείνω ντιλ | **κλείνω** συμφωνία / δουλειά / παραγγελία |

## 14. Εκφράσεις που δουλεύουν στο marketing
Οι ιδιωτισμοί έχουν «ανεπίσημο, προφορικό χαρακτήρα» (Τηλικίδου, ΙΝΣ Μελέτες για την ελληνική γλώσσα 38). Ταιριάζουν σε social, χαλαρό copy και chat, λιγότερο σε B2B προτάσεις. Η σημασία κάθε έκφρασης είναι επιβεβαιωμένη στο ΛΚΝ.

**✓ Χρήσιμες (θετικές, ζεστές)**
| Έκφραση | Σημασία (ΛΚΝ) | Παράδειγμα copy |
|---|---|---|
| κάνω τα αδύνατα δυνατά | προσπαθώ με κάθε μέσο | «Κάνουμε τα αδύνατα δυνατά για να είναι όλα έτοιμα στην ώρα τους.» |
| βάζω τα δυνατά μου | καταβάλλω κάθε προσπάθεια | «Βάζουμε τα δυνατά μας σε κάθε ποτήρι.» |

| κάνω ποδαρικό | φέρνω καλή/κακή τύχη ως πρώτος επισκέπτης | Πρωτοχρονιά: «Κάντε ποδαρικό με κοκτέιλ.» |
| με όλη μου την καρδιά / από καρδιάς | εγκάρδια | «Σας ευχαριστούμε από καρδιάς.» |
| κάνω εντύπωση | προκαλώ ζωηρό ενδιαφέρον | «Ένα μπαρ που κάνει εντύπωση από την πρώτη στιγμή.» |

| μου κάνει κέφι | μου αρέσει | social: «Σας κάνει κέφι ένα κοκτέιλ στην παραλία;» |
| είναι του γούστου μου | μου αρέσει | «Διαλέξτε κοκτέιλ του γούστου σας.» |
| και βάλε | και περισσότερο | «200 καλεσμένοι και βάλε; Κανένα πρόβλημα.» |

**✗ Μην τις χρησιμοποιείς για το brand (αρνητική σημασία στο ΛΚΝ)**
- τα κάνω θάλασσα / μούσκεμα / σαλάτα (τα καταστρέφω)
- κάνω μια τρύπα στο νερό (δεν πετυχαίνω τίποτα)
- βάζω φέσι (δεν πληρώνω χρέος)
- κάνω το κέφι μου (στο ΛΚΝ: «χωρίς να λογαριάζω κανέναν»· διφορούμενο)

**Κανόνες**
- Μία έκφραση ανά ενότητα, όχι συλλογή. Μην τις «προσαρμόζεις» (✗ «κάνουμε τα δυνατά αδύνατα»).
- Μη μεταφράζεις αγγλικούς ιδιωτισμούς (5.2 #15–17). Βρες αντίστοιχη ελληνική ή γράψε απλά.

## 17. UX και microcopy (κουμπιά, φόρμες, μηνύματα)
Πηγή: Microsoft Greek Style Guide (μηνύματα σφάλματος, ύφος, στίξη).

### 17.1 Μηνύματα σφάλματος και ειδοποιήσεις
- **Όχι θαυμαστικό**, όχι «Παρακαλώ» σε κάθε μήνυμα. Ευγένεια = σαφήνεια.
- Δομή για αδυναμία: «**Δεν είναι δυνατή η** αποστολή της φόρμας.» / «**Δεν ήταν δυνατό** το άνοιγμα του αρχείου.» Ή απλούστερα στο marketing: «Δεν στάλθηκε το μήνυμα. Δοκιμάστε ξανά.»
- Πες τι έγινε και τι να κάνει ο χρήστης, σε δύο σύντομες προτάσεις: «Το email δεν είναι σωστό. Ελέγξτε το και δοκιμάστε ξανά.»
- Οδηγίες βημάτων με άνω-κάτω τελεία: «**Κάντε τα εξής:**» και μετά λίστα.
- Checkbox / επιλογές ως φράση με «να»: «**Να μην εμφανιστεί ξανά.**»
- «**Επιλέξτε**» αντί για «Κάντε κλικ» (δουλεύει και σε κινητό). Στο marketing ακόμα καλύτερα, το ρήμα της πράξης: «Δείτε τα πακέτα».

### 17.2 Κουμπιά και τίτλοι
- Κουμπί = στιγμιαία προστακτική ή ουσιαστικό: «Αποστολή», «Στείλτε μήνυμα», «Ζητήστε προσφορά». Ένα στυλ ανά site.
- Τίτλοι σε **sentence case** (κεφαλαίο μόνο η πρώτη λέξη και κύρια ονόματα), χωρίς τελεία.
- Αριθμοί **κάτω από το 10 ολογράφως** στο κείμενο («τρία βήματα»), ψηφία σε τιμές, μονάδες και χρόνους («σε 3 λεπτά» σε κουμπί είναι αποδεκτό για χώρο).
- Χωρίς συντετμημένους τύπους με απόστροφο σε κουμπιά και μενού (✗ «Πάρ' το τώρα»). Η Microsoft τους επιτρέπει μόνο σε λίγες σταθερές φράσεις (δες §19).

### 17.3 Συμπεριληπτική γλώσσα
- Γενίκευση με πληθυντικό ή ουδέτερο: «άτομα», «καλεσμένοι», «όσοι κλείνουν» αντί για «ο χρήστης… αυτός».
- «άτομο με αναπηρία» (✗ ανάπηρος ως ουσιαστικό, ✗ «κανονικό άτομο» για άτομο χωρίς αναπηρία).
- Για ρόλους: ουσιαστικά κοινού γένους με άρθρο ανάλογα με το πρόσωπο (ο/η bartender, ο/η DJ, ο/η υπεύθυνος/η).

### 17.4 Συντομογραφίες (Microsoft, ΕΕ)
| Πλήρες | Συντομογραφία |
|---|---|
| αριθμός | αρ. |
| βλέπε | βλ. |
| δηλαδή | δηλ. |
| και άλλα | κ.ά. |
| και τα λοιπά | κ.λπ. ή κτλ. (ένα στυλ σε όλο το κείμενο) |
| και ούτω καθεξής | κ.ο.κ. |
| τετραγωνικά μέτρα | τ.μ. |
| χιλιόμετρα | χλμ. (ή km στις μονάδες SI) |
| υστερόγραφο | ΥΓ. |
| για παράδειγμα | π.χ. |
- Οι συντομογραφίες **δεν παίρνουν πληθυντικό** (αρ. για «αριθμοί»).
- Αν η πρόταση τελειώνει σε συντομογραφία με τελεία, δεν μπαίνει δεύτερη τελεία.
- Στο marketing γράψε ολόκληρη τη λέξη όπου χωράει.

## 18. Στίξη: συμπληρώσεις και διορθώσεις (ΕΕ 10.1.7–10.1.8, Microsoft)

### 18.1 Εισαγωγικά σε επίπεδα
1. «…» (γωνιώδη) πρώτα.
2. “…” μέσα σε «».
3. ‘…’ στο τρίτο επίπεδο.
✓ Μας είπε: «Θέλω το “Aperol Spritz” όπως στο ‘Il Bar’».
Η τελεία μπαίνει **έξω** από τα εισαγωγικά όταν τα εισαγωγικά κλείνουν μέρος της πρότασης.

### 18.2 Παύλες και ενωτικό
| Σημείο | Χρήση | Παράδειγμα |
|---|---|---|
| **-** ενωτικό (hyphen) | σύνθετα, αλλαγή γραμμής, διπλά επώνυμα, εύρος αριθμών με ίδια μονάδα | λέξη-κλειδί, Παπαδοπούλου-Νικολάου, 25-45 ετών, 10-70 kg |
| **–** μεσαία παύλα (en dash) | σχέση δύο όρων, διαστήματα, πλην | σχέσεις ΕΕ–Αιγύπτου, Αθήνα–Θεσσαλονίκη, 20:00–02:00, – 7 °C |
| **—** μακριά παύλα (em dash) | παρενθετική φράση, **σε ζεύγος, χωρίς κενό μέσα**· κενό πριν από την πρώτη και μετά τη δεύτερη | Το van —με δύο bartenders— στήνεται σε μία ώρα. |
| **—** μόνη | στο τέλος πρότασης, για έμφαση | Όλα είναι έτοιμα —και στην ώρα τους. |
| **—** σε λίστα/διάλογο | αρχή στοιχείου λίστας ή ομιλητή | — Πόσοι θα είστε; |
- **Διόρθωση της v1:** η v1 έλεγε «— με κενά». Κατά ΕΕ και Microsoft η μακριά παύλα **δεν έχει κενά μέσα** στο ζεύγος. Στο web, αν το font δείχνει την em dash κολλημένη, χρησιμοποίησε κόμματα ή παρένθεση αντί για παύλα (πιο ελληνικό, και λιγότερο «AI» ύφος).
- Όταν οι μονάδες διαφέρουν, το ενωτικό στο εύρος μπαίνει με κενά: 200 kW - 10 MW (ΕΕ). Στο copy γράψε «από 200 kW έως 10 MW».

### 18.3 Κόμμα: συμπληρώσεις
- **Χωρίς κόμμα** μετά από σύντομο χρονικό ή τοπικό προσδιορισμό στην αρχή: ✓ «Το καλοκαίρι στήνουμε μπαρ σε όλη την Αττική.» (ΕΕ)
- **Με κόμμα** μετά από συνδέσμους-επιρρήματα στην αρχή: «Συνεπώς,», «Ως εκ τούτου,», «Αντίθετα,», «Επομένως,» (ΕΕ). Στο marketing καλύτερα «Έτσι» χωρίς κόμμα.
- **Με κόμματα** η επεξήγηση και η παράθεση: «Ο Γιώργος, ο ιδιοκτήτης, θα σας καλέσει.»
- **Όχι κόμμα** ανάμεσα σε ρήμα και αντικείμενο: ✗ «Προσφέρουμε, κοκτέιλ και αναψυκτικά».

### 18.4 Άλλα
- **Άνω και κάτω τελεία:** μετά από αυτή, **πεζό** γράμμα, εκτός αν ακολουθεί ευθύς λόγος ή ετικέτα «Προσοχή:», «Σημείωση:» (Microsoft).
- **Παρενθέσεις:** χωρίς κενό μέσα: ✓ (έως 200 άτομα).
- **Αποσιωπητικά:** πάντα **τρεις** τελείες (…), ποτέ δύο ή τέσσερις (ΕΕ).
- **Λίστες:** στοιχεία που είναι πλήρεις προτάσεις παίρνουν τελεία· φράσεις χωρίς τελεία. Ένα στυλ σε όλη τη λίστα (Microsoft).
- **Κενό χωρίς αλλαγή γραμμής:** ανάμεσα σε αριθμό και μονάδα/νόμισμα (450&nbsp;€, 14&nbsp;°C). Στο HTML `&nbsp;` (ΕΕ: τα ποσά δεν κόβονται σε δύο γραμμές).

## 21. Έλεγχος πριν από την αποστολή (15 σημεία)

1. Κάθε λέξη 2+ συλλαβών έχει τόνο· μονοσύλλαβα (μια, για, πια, ποιος, τρεις) χωρίς τόνο· ή/πού/πώς σωστά.
2. Εγκλιτικά μετά από προπαροξύτονη: το τηλέφωνό σας, η κράτησή σας.
3. ALL CAPS χωρίς τόνους, με διαλυτικά όπου χρειάζεται (ΜΑΪΟΣ).
4. -ται / -τε, της / τις / τους, -ής / -είς, ό,τι / ότι· στιγμιαίο θέμα για μία ενέργεια (εισαγάγετε, υποβάλετε, προβάλουμε) (§10.1).
5. Τελικό -ν: τον, έναν πάντα· τη(ν), δε(ν), μη(ν) με **έναν** κανόνα σε όλο το κείμενο.
6. Ερωτηματικό «;», εισαγωγικά «» και μέσα “ ”, κανένα κενό πριν από στίξη ή μέσα σε παρένθεση, – για διαστήματα, — σε ζεύγος χωρίς κενά μέσα, … τρεις τελείες (§18).
7. Χωρίς κόμμα πριν από ότι/πως/να/αν (=whether) και ανάμεσα σε ρήμα και αντικείμενο· κόμμα μετά από υποθετική που προηγείται.
8. Συμφωνία γένους/αριθμού/πτώσης, και στις ξένες λέξεις (το mobile bar είναι διαθέσιμο)· «όλους όσοι» χωρίς έλξη· μετοχή με το ίδιο υποκείμενο με το ρήμα (§9.2, §9.4).
9. Ρήματα αντί για αλυσίδες ουσιαστικών· ενεργητική φωνή· όχι πάνω από δύο γενικές στη σειρά· όχι υπερβατό (§9.1).
10. Κτητικά (σας/μας) μόνο όπου χρειάζονται, στο τέλος της φράσης.
11. Καμία φράση από τη λίστα 5.2, κανένας ψευδόφιλος (§15), καμία σύμφραση κατά λέξη (§13). Διάβασέ το δυνατά: «ακούγεται μεταφρασμένο;»
12. Ένα ύφος (εσείς ή εσύ) σε όλο το κείμενο· ευγενικός πληθυντικός με επίθετο στον ενικό για ένα άτομο· απλή λέξη αντί για λόγια (§16.1).
13. Κεφαλαία: μήνες/ημέρες κεφαλαίο, γλώσσες/εποχές/αξιώματα πεζό, τίτλοι σε sentence case.
14. Αριθμοί: 1.250,50 €, 14:00, 23 Οκτωβρίου 2026, +30 694 123 4567, τρεισήμισι ώρες / τριάμισι χρόνια· κανένας αριθμός χωρίς πηγή.
15. SEO/UX: keyword σωστά τονισμένο και σε φυσική πτώση, title/description στο μήκος, CTA 2–4 λέξεις με στιγμιαία προστακτική, μηνύματα σφάλματος χωρίς θαυμαστικό και «Παρακαλώ» (§17).
