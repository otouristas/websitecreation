# Report specification

Phase 1 does not render private reports and does not add them to the sitemap. This is the contract for the follow-up.

## SEO report

Show the period and how fresh the data is. Name the programme month. List tasks with URLs. Before and after only where both observations exist. Google Search Console: clicks, impressions, CTR as sum of clicks divided by sum of impressions, and a weighted average position (impression-weighted), not a simple average of daily positions. GA4 only when the property is verified for that project. If the month is partial, say so. Do not invent AI-visibility figures and do not fill missing days with zeroes.

## Care report

Plan limit in minutes, real minutes per task, exceptions (our bugs, admin, billing — not charged), extras approved separately, and the balance. Alert copy exists for 80% and for the last minutes, but the mailer is not wired.

## Combined

One document only when the client has both an SEO programme and a care plan. Otherwise they stay separate.

## Admin

Contract value ex-VAT, collected, owed, planned hours versus logged minutes, committed capacity. Revenue per hour only when real cost data exists. This phase has no cost ledger, so that ratio is not shown.

## Delivery

HTML that prints. Export is a later check. Authorization is required. Private URLs stay out of `sitemap.ts`.
