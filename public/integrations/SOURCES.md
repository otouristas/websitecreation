# Service marks

Bundled locally; no requests to logo/CDN services from wp-admin. Decorative marks always accompany a written service name. No endorsement is implied.

* SVG files: exact existing `ios/docs/service-logo-sources/` assets. See `ios/docs/SERVICE_LOGOS.md` and `src/components/brand/logos/LICENSES.md` for provenance (LobeHub MIT / Simple Icons CC0).
* Ahrefs compact PNG: original, unmodified compact logo for small spaces from https://ahrefs.com/logo → https://ahrefs.com/assets/esbuild/a-blue-G6X776CO.png, retrieved 2026-10-15. Trademark belongs to Ahrefs. No filters or redraw.

* Chrome uses Google's published SVG at https://www.google.com/chrome/static/images/chrome-logo.svg.
* Model Context Protocol uses the project's mark at https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/favicon.svg.
* Android uses the Android brand mark from Simple Icons at https://cdn.simpleicons.org/android.
* Apple, X, Gemini, Claude, ChatGPT and Perplexity use the same licensed service vectors as the CRM and native apps.
* LinkedIn uses the mark from Simple Icons 13.21.0 (CC0) in its official blue, https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/linkedin.svg.
* Google Search Console uses the 40×40 standalone symbol from Google's current lockup at https://gstatic.com/search-console/scfe/logo_search_console.svg.
* Google Analytics uses the original two-color mark at https://github.com/gilbarbara/logos/blob/main/logos/google-analytics.svg.
