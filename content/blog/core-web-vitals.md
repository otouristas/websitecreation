**Τα Core Web Vitals είναι τρεις μετρήσεις της Google για την εμπειρία χρήστη: το LCP (πόσο γρήγορα εμφανίζεται το κύριο περιεχόμενο), το INP (πόσο γρήγορα αντιδρά η σελίδα σε κλικ) και το CLS (πόσο «χορεύει» η διάταξη). Καλά όρια: LCP έως 2,5 s, INP έως 200 ms, CLS έως 0,1, στο 75ο εκατοστημόριο των πραγματικών επισκέψεων.** Μετρούν για την κατάταξη, αλλά λιγότερο απ' όσο νομίζουν πολλοί. Μετρούν πολύ για τις πωλήσεις.

Τα Core Web Vitals είναι ένα κομμάτι του [τεχνικού SEO](/el/blog/techniko-seo). Εδώ θα δείτε τι σημαίνει κάθε μέτρηση, πώς τη διαβάζετε σωστά και τι διορθώνετε πρώτο, με ειδικές συμβουλές για WordPress.

## Τι Μετρά Κάθε Core Web Vital

| Μέτρηση | Τι μετρά | Καλό | Χρειάζεται βελτίωση | Κακό |
|---|---|---|---|---|
| [LCP](/el/glossary/lcp) | Χρόνο μέχρι να εμφανιστεί το μεγαλύτερο στοιχείο (εικόνα ή μπλοκ κειμένου) | έως 2,5 s | 2,5-4 s | πάνω από 4 s |
| [INP](/el/glossary/inp) | Καθυστέρηση από κλικ ή πάτημα μέχρι να ενημερωθεί η οθόνη | έως 200 ms | 200-500 ms | πάνω από 500 ms |
| [CLS](/el/glossary/cls) | Απρόσμενες μετακινήσεις της διάταξης | έως 0,1 | 0,1-0,25 | πάνω από 0,25 |

Η σελίδα «περνά» όταν τουλάχιστον το 75% των επισκέψεων είναι στο «Καλό» και για τις τρεις μετρήσεις. Το κινητό και ο υπολογιστής αξιολογούνται χωριστά, και στις περισσότερες ελληνικές ιστοσελίδες το κινητό είναι εκεί που αποτυγχάνουν.

Το INP αντικατέστησε το FID τον Μάρτιο του 2024. Η διαφορά είναι ουσιαστική: το FID μετρούσε μόνο την πρώτη αλληλεπίδραση, ενώ το INP μετρά όλες, οπότε ένα βαρύ φίλτρο προϊόντων ή ένα μενού που κολλάει πλέον φαίνεται.

## Δεδομένα Πεδίου και Δεδομένα Εργαστηρίου

Εδώ γίνονται τα περισσότερα λάθη.

- **Δεδομένα πεδίου (field data)** προέρχονται από πραγματικούς χρήστες Chrome (Chrome UX Report) και καλύπτουν κυλιόμενο διάστημα 28 ημερών. Αυτά χρησιμοποιεί η Google για την εμπειρία σελίδας.
- **Δεδομένα εργαστηρίου (lab data)** προέρχονται από μία προσομοιωμένη φόρτωση στο Lighthouse. Είναι χρήσιμα για διάγνωση, αλλά δεν είναι αυτά που μετρούν για την κατάταξη. Το Lighthouse δεν μετρά INP, γιατί δεν κάνει κλικ. Χρησιμοποιεί το Total Blocking Time ως ένδειξη.

Ένα σκορ 45/100 στο PageSpeed Insights με πράσινα δεδομένα πεδίου σημαίνει ότι οι πραγματικοί επισκέπτες σας είναι εντάξει. Το αντίστροφο, 95/100 με κόκκινο πεδίο, σημαίνει πρόβλημα. Σελίδες με λίγη επισκεψιμότητα συχνά δεν έχουν καθόλου δεδομένα πεδίου, οπότε κρίνετε από το template στο σύνολό του.

## Πώς Ελέγχετε τα Core Web Vitals

### Βήμα 1: Ανοίξτε την αναφορά Core Web Vitals στο Search Console

Δείτε χωριστά κινητό και υπολογιστή και σημειώστε ποιες ομάδες URL είναι «Χρειάζεται βελτίωση» ή «Κακή» και για ποια μέτρηση.

### Βήμα 2: Ελέγξτε ένα αντιπροσωπευτικό URL στο PageSpeed Insights

Διαβάστε πρώτα τα δεδομένα πεδίου στο πάνω μέρος και μετά τη διάγνωση Lighthouse για να βρείτε το στοιχείο LCP, τα αργά scripts ή τα στοιχεία που μετακινούνται.

### Βήμα 3: Διορθώστε το template, όχι μία σελίδα

Εφαρμόστε τη διόρθωση στο πρότυπο που μοιράζονται οι σελίδες της ομάδας, για παράδειγμα στη σελίδα προϊόντος ή στο άρθρο.

### Βήμα 4: Επιβεβαιώστε με δεδομένα πεδίου μετά από 28 ημέρες

Πατήστε «Επικύρωση διόρθωσης» στο Search Console και περιμένετε να ανανεωθούν τα δεδομένα πεδίου, γιατί καλύπτουν κυλιόμενο διάστημα 28 ημερών.

## Διορθώσεις ανά Μέτρηση

| Μέτρηση | Συχνή αιτία | Διόρθωση |
|---|---|---|
| LCP | Μεγάλη hero εικόνα σε JPEG/PNG | WebP ή AVIF, σωστές διαστάσεις, `fetchpriority="high"` στην εικόνα LCP |
| LCP | Αργός server (υψηλό TTFB) | Καλύτερο hosting, page cache, CDN |
| LCP | Lazy-load στην πρώτη εικόνα | Αφαιρέστε το lazy-load από την εικόνα πάνω από την πτυχή |
| INP | Βαριά JavaScript από plugins και τρίτους | Λιγότερα scripts, `defer`, φόρτωση chat και widgets μετά την αλληλεπίδραση |
| INP | Μεγάλα DOM από page builders | Απλούστερα templates, λιγότερα εμφωλευμένα στοιχεία |
| CLS | Εικόνες και iframes χωρίς διαστάσεις | Ορίστε `width` και `height` ή `aspect-ratio` |
| CLS | Banner cookies και διαφημίσεις που σπρώχνουν το περιεχόμενο | Δεσμεύστε χώρο ή εμφανίστε τα ως επικάλυψη |
| CLS | Web fonts που αλλάζουν μέγεθος κειμένου | Preload της βασικής γραμματοσειράς, `font-display` και fallback με παρόμοιες διαστάσεις |

## Συμβουλές για WordPress

- **Μετρήστε τα plugins.** Κάθε plugin που φορτώνει CSS και JavaScript σε όλες τις σελίδες επιβαρύνει το INP. Απενεργοποιήστε ό,τι δεν χρησιμοποιείτε και φορτώστε φόρμες ή sliders μόνο στις σελίδες που τα χρειάζονται.
- **Page cache και object cache.** Ένα plugin cache ή cache στο επίπεδο του hosting μειώνει το TTFB και άρα το LCP.
- **Προσοχή στα page builders.** Τα βαριά builders παράγουν μεγάλο HTML. Σε νέα ιστοσελίδα, ένα ελαφρύ θέμα με block editor συνήθως ξεκινά από καλύτερη βάση.
- **Εικόνες.** Ανεβάζετε εικόνες στο μέγεθος που εμφανίζονται και αφήνετε το WordPress να δίνει `srcset`. Ελέγξτε ότι το θέμα δεν βάζει lazy-load στην πρώτη εικόνα.
- **Scripts τρίτων.** Chat, heatmaps και pixels είναι συχνά η μεγαλύτερη αιτία κακού INP. Κρατήστε μόνο όσα χρησιμοποιείτε.

Για e-shop σε WooCommerce, οι σελίδες κατηγορίας με φίλτρα είναι συνήθως το πρώτο template που αποτυγχάνει στο INP.

## Πόσο Μετρούν για την Κατάταξη

Ειλικρινά: λίγο. Τα Core Web Vitals είναι μέρος της [εμπειρίας σελίδας](/el/glossary/page-experience), και η Google έχει πει ότι η σχετικότητα του περιεχομένου μετρά περισσότερο. Μια αργή σελίδα που απαντά καλύτερα στο ερώτημα θα κερδίζει συχνά μια γρήγορη που απαντά χειρότερα. Λειτουργούν περισσότερο ως κριτήριο ισοπαλίας ανάμεσα σε παρόμοιες σελίδες.

Γιατί να ασχοληθείτε λοιπόν; Επειδή μια σελίδα που αργεί ή «πηδάει» χάνει επισκέπτες πριν διαβάσουν, και αυτό φαίνεται στο ποσοστό μετατροπής. Διορθώστε πρώτα τα templates που φέρνουν πελάτες: σελίδες υπηρεσιών, προϊόντων και κρατήσεων. Αν χρησιμοποιείτε [schema markup](/el/blog/schema-markup), ο ίδιος έλεγχος template είναι καλή ευκαιρία να το επαληθεύσετε.

## Θέλετε Πράσινα Core Web Vitals στις Σελίδες που Πουλάνε;

Η υπηρεσία [βελτιστοποίησης ταχύτητας](/el/services/speed-optimization) ξεκινά από τα δεδομένα πεδίου του Search Console και διορθώνει τα templates με τη μεγαλύτερη επισκεψιμότητα. Για πλήρη εικόνα της ιστοσελίδας ζητήστε ένα [SEO audit](/el/services/seo-audits) ή [ξεκινήστε εδώ](/el/get-started).

## Συχνές Ερωτήσεις

### Τι είναι τα Core Web Vitals;

Τρεις μετρήσεις εμπειρίας χρήστη της Google: LCP για τη φόρτωση του κύριου περιεχομένου, INP για την απόκριση σε κλικ και CLS για τη σταθερότητα της διάταξης.

### Ποια είναι τα καλά όρια για LCP, INP και CLS;

LCP έως 2,5 s, INP έως 200 ms και CLS έως 0,1, στο 75ο εκατοστημόριο των πραγματικών επισκέψεων, χωριστά για κινητό και υπολογιστή.

### Επηρεάζουν τα Core Web Vitals την κατάταξη στη Google;

Ναι, με μικρό βάρος, ως μέρος της εμπειρίας σελίδας. Η σχετικότητα του περιεχομένου μετρά περισσότερο.

### Γιατί το PageSpeed Insights δείχνει άλλο σκορ από το Search Console;

Το σκορ προέρχεται από δοκιμή εργαστηρίου. Το Search Console δείχνει δεδομένα πεδίου από πραγματικούς χρήστες.

### Τι αντικατέστησε το FID;

Το INP, από τον Μάρτιο του 2024.
