Google does not publish a numbered list of ranking factors. [How Google Search works](https://developers.google.com/search/docs/fundamentals/how-search-works) says relevancy is determined by hundreds of factors, which can include the searcher's location, language and device. The public record of the systems behind that is [A guide to Google Search ranking systems](https://developers.google.com/search/docs/appearance/ranking-systems-guide). This page separates what that documentation confirms from claims it contradicts. It does not forecast positions or traffic.

If the process is new to you, start with [what SEO is](/en/blog/what-is-seo). The work you can change on a URL sits in [on-page SEO](/en/blog/on-page-seo), [technical SEO](/en/blog/technical-seo-guide) and [off-page SEO](/en/blog/off-page-seo).

## What Google says ranking is

Ranking systems work on the page. Site-wide signals also exist, but Google says a strong site-wide signal does not make every URL rank, and a weak one does not sink every URL. Changes are tested, and Google announces ranking updates when that is useful to creators.

Four distinctions matter before any checklist:

- **Understanding systems** such as BERT, RankBrain, neural matching and passage ranking match meaning. They are not settings you turn on. RankBrain can return a relevant page even when some query words are missing.
- **Link systems**, including PageRank, still read how pages link to each other. PageRank remains part of core ranking. Penguin, the 2012 link-spam system, was folded into core ranking in 2016.
- **Quality systems** favour original reporting, reliable information and high-quality reviews. The helpful-content system from 2022 became part of core ranking in March 2024.
- **MUM** is not used for general ranking. Google limits it to specific applications, such as some featured-snippet callouts.

## Confirmed signals you can act on

[Structured data](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data) is documented as a way to label what is on the page so Google can understand it and, when the page is eligible, show a rich result. It is not listed as a ranking system. Use it only when the markup matches visible content, as the [technical SEO guide](/en/blog/technical-seo-guide) describes.

## Myths the documentation contradicts

These claims still show up in checklists. Each one conflicts with a current Google page.

1. **The keywords meta tag ranks you.** Google's web search [does not use the keywords meta tag](https://developers.google.com/search/blog/2009/09/google-does-not-use-keywords-meta-tag). The post still says that has not changed.
2. **You can pay for a higher organic position.** [How Search works](https://developers.google.com/search/docs/fundamentals/how-search-works) says Google does not accept payment to rank pages higher. Ads are separate.
3. **A higher crawl rate is a ranking factor.** [Crawling myths](https://developers.google.com/crawling/docs/myths-about-crawling) says crawling is required for a page to be eligible, but crawl rate is not a ranking signal.
4. **Trivial edits and a new date make a page fresh.** [Crawling myths](https://developers.google.com/crawling/docs/myths-about-crawling) says quality is judged regardless of age, and date-only edits add nothing. The [helpful-content guide](https://developers.google.com/search/docs/fundamentals/creating-helpful-content) says changing dates, or adding and removing pages just to look fresh, will not help.
5. **Pages closer to the homepage rank higher.** A homepage link can mean more frequent crawling. Google says that is not a higher rank.
6. **An exact-match domain is a ranking boost.** Domain words can show relevance. The exact-match system stops a query-shaped name from propping up weak content.
7. **Repeating the keyword is a factor.** [Keyword stuffing](https://developers.google.com/search/docs/essentials/spam-policies) is spam: unnatural lists, city-name blocks, or a phrase repeated until it sounds wrong.
8. **Buying or exchanging links is normal off-page SEO.** [Link spam](https://developers.google.com/search/docs/essentials/spam-policies) includes paid links that pass credit, excessive exchanges and keyword-rich footers. Earn mentions as the [link building guide](/en/blog/link-building-guide) describes.
9. **A perfect Core Web Vitals grade wins the query.** [Page experience](https://developers.google.com/search/docs/appearance/page-experience) says there is no single signal. Beyond Core Web Vitals, other page-experience aspects do not directly raise rank, though they can make a page more usable. Metric definitions are in [Core Web Vitals](https://developers.google.com/search/docs/appearance/core-web-vitals).
10. **E-E-A-T is a factor you add with an author box.** Google says E-E-A-T itself is not a ranking factor. Rater data is not used directly in ranking. A byline shows who wrote the page. A fabricated expert bio is deception.
11. **Google prefers a word count.** The helpful-content page says no.
12. **MUM ranks your site, or helpful content is still a separate penalty.** MUM is not a general ranker. Helpful content joined core systems in March 2024.

Social likes, a Google Analytics bounce rate and domain-registration length are not named in the ranking-systems guide. That absence is not a denial, so this article does not list them as confirmed myths.

## What to change on the site

Use the documented systems, in this order:

1. Answer one query in the title, H1 and opening. That is [on-page SEO](/en/blog/on-page-seo) and [SEO content](/en/blog/seo-content-guide), not a density target.
2. Keep the URL crawlable, indexable and honestly canonical. See [technical SEO](/en/blog/technical-seo-guide). Crawl rate is not the ranking lever.
3. Hold Core Web Vitals in a good range on templates that earn impressions. Skip a perfect lab score on thin copy.
4. Publish something a reader cannot get by rewriting the current results.
5. Earn relevant links and drop manipulative ones. Read [off-page SEO](/en/blog/off-page-seo).
6. Use Search Console for the queries the URL already appears for. A factor checklist cannot name the URL Google is choosing.

For map results, use the [local SEO guide](/en/blog/local-seo-guide). This web-ranking list does not describe Google Business Profile.
