Το **hosting** και το **domain** είναι τα θεμέλια κάθε ιστοσελίδας - και οι δύο αποφάσεις που οι περισσότερες επιχειρήσεις παίρνουν βιαστικά, με κριτήριο μόνο την τιμή. Ένα κακό hosting όμως κοστίζει σε ταχύτητα (άρα σε Google κατατάξεις), σε downtime (άρα σε χαμένους πελάτες) και σε ασφάλεια. Ας τα δούμε σωστά.

## Domain: .gr ή .com;

- **.gr**: η προφανής επιλογή για επιχείρηση που απευθύνεται στην ελληνική αγορά. Σηματοδοτεί τοπικότητα σε χρήστες και μηχανές αναζήτησης. Κόστος: ~€10-15/χρόνο (κατοχύρωση διετίας).
- **.com**: για διεθνή στόχευση (τουρισμός, εξαγωγές, SaaS). Αν απευθύνεστε και στα δύο κοινά, ιδανικά κατοχυρώστε και τα δύο και ορίστε το ένα ως κύριο.
- Αποφύγετε «εξωτικές» καταλήξεις (.xyz, .site) για εταιρική χρήση - υπονομεύουν την εμπιστοσύνη σε ελληνικό κοινό.

**Συμβουλές κατοχύρωσης**: κρατήστε το domain σε δικό σας λογαριασμό (όχι του κατασκευαστή), ενεργοποιήστε auto-renew, και κατοχυρώστε τις προφανείς παραλλαγές (με/χωρίς παύλα) πριν το κάνει ανταγωνιστής.

## Hosting: Τι Πραγματικά Μετράει

### Ταχύτητα (και για το SEO)

Η Google μετρά τα Core Web Vitals - και ο server είναι το πρώτο δευτερόλεπτο της εξίσωσης. Ζητήστε: NVMe δίσκους, PHP 8.3+, HTTP/2 ή HTTP/3, server ή CDN κόμβο στην Ευρώπη. Ένα φθηνό shared hosting των €2/μήνα με TTFB 800ms υπονομεύει κάθε ευρώ που επενδύετε σε [SEO](/el/services/local-seo).

### Τύποι hosting και τιμές στην Ελλάδα

| Τύπος | Κόστος/μήνα | Για ποιον |
| :--- | :--- | :--- |
| Shared hosting | €3 - €10 | Μικρά sites, blogs |
| Managed WordPress | €10 - €35 | Εταιρικά sites, e-shop με μέτρια κίνηση |
| VPS | €20 - €80 | E-shop με κίνηση, πολλαπλά sites |
| Dedicated / Cloud | €80+ | Υψηλή επισκεψιμότητα, custom ανάγκες |

### Ασφάλεια και backups

Δωρεάν SSL (Let's Encrypt) είναι πλέον αυτονόητο. Ζητήστε ημερήσια αυτόματα backups με εύκολη επαναφορά, firewall εφαρμογής (WAF) και απομόνωση λογαριασμών στο shared περιβάλλον.

### Υποστήριξη στα ελληνικά;

Για πολλές επιχειρήσεις, η ελληνόφωνη υποστήριξη αξίζει μερικά ευρώ παραπάνω. Εναλλακτικά, με συμβόλαιο [συντήρησης](/el/pricing) το τεχνικό κομμάτι το αναλαμβάνει ο συνεργάτης σας και το hosting επιλέγεται καθαρά με τεχνικά κριτήρια.

## Τα 4 Συχνότερα Λάθη

1. **Domain στο όνομα του κατασκευαστή**: αν χαλάσει η συνεργασία, κρατά όμηρο το brand σας. Πάντα σε δικό σας λογαριασμό.
2. **Hosting με κριτήριο μόνο την τιμή**: τα €5/μήνα που «γλιτώνετε» τα πληρώνετε σε αργό site και χαμένες κατατάξεις.
3. **Χωρίς backups**: ένα hack ή ένα λάθος update χωρίς backup σημαίνει κατασκευή από την αρχή.
4. **Email στο ίδιο πακέτο με το site**: για εταιρικό email προτιμήστε Google Workspace ή Microsoft 365 - το hosting email καταλήγει συχνά στα spam των παραληπτών.

## Συχνές Ερωτήσεις

### Πόσο κοστίζει συνολικά η «συντήρηση ζωής» μιας ιστοσελίδας;

Domain ~€12/χρόνο + hosting €120-400/χρόνο + προαιρετική τεχνική συντήρηση. Δείτε τη συνολική εικόνα κόστους στον οδηγό [πόσο κοστίζει μια ιστοσελίδα](/el/blog/poso-kostizei-mia-istoselida).

### Μπορώ να αλλάξω hosting χωρίς να χάσω το SEO;

Ναι - η μεταφορά hosting δεν αλλάζει URLs, άρα δεν αγγίζει κατατάξεις, αρκεί να γίνει χωρίς downtime και με σωστό DNS χειρισμό. Διαφορετικό θέμα ο [ανασχεδιασμός](/el/blog/anasxediasmos-istoselidas), που θέλει migration πλάνο.

### Το e-shop μου θέλει διαφορετικό hosting;

Ναι: περισσότερη μνήμη, object caching και συχνότερα backups. Στον [οδηγό κατασκευής e-shop](/el/blog/kataskevi-eshop-odigos) καλύπτουμε τις απαιτήσεις αναλυτικά.
